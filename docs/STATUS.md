## Arquitetura
- **Padrão de tela:** página em `src/pages/` é fina (repassa `filters` do `AppShell`) e delega pra um componente pesado em `src/components/dashboard/` (ex: `ServicosPatio.tsx` ~250B → `PatioTab.tsx` 20.9KB). Não é placeholder — é o padrão do projeto inteiro.
- **Duas vias de dado:** views leves via `supabase.from()` direto (tipadas em `types.ts`, schema **compartilhado com outros apps Bononi** — `loja_*`/`taco_*` não estão tipadas nele). Views comerciais pesadas (Vendas/Serviços) passam pela **Edge Function `fetch-comercial`** (`supabase/functions/fetch-comercial/`, neste repo desde 05/10/2026; publica pelo CLI com `--no-verify-jwt`, skill `publicar-edge-function`) via `fetch()` cru + anon key.

Lição: `intervalo_min_minutos` sempre tem que ficar **abaixo** do intervalo do `cron.job`, nunca igual.
